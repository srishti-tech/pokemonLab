# Pokemon Card Lab

Updated dashboard with:
- Home dashboard
- Search Pokemon by name or ID
- Search by Type (loads all Pokemon of the selected type)
- Mystery Card random reveal
- Battle with two Pokemon search fields
- Full Pokemon detail modal
- My Collection page
- Search Pokemon from My Collection and add them
- Add to Collection from Pokemon details/search
- Remove individual Pokemon from collection
- Clear entire collection
- Collection is persisted in browser localStorage
- Responsive dark Pokemon dashboard UI

Open `index.html` in a browser.

The app uses PokéAPI, so an internet connection is required.

- Pokémon Info page replacing Generate
- Search any Pokémon and view its complete evolution family, including pre-evolutions and branching evolution stages
